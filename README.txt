МОЯ ТЕХНИЧЕСКАЯ БАЗА — набор файлов для установки как приложение (PWA)

Состав:
  index.html              сама программа (версия 1.25)
  manifest.webmanifest    описание приложения (название, значки, цвета)
  sw.js                   кэш для работы без сети
  icons/                  значки приложения

ВАЖНО
1. PWA работает только по адресу https:// (или http://localhost).
   Двойной щелчок по index.html (адрес file://) установку и офлайн-кэш не включает,
   но программа при этом работает как обычно.
2. Данные хранятся в браузере отдельно для каждого адреса сайта.
   Версия из одиночного файла и версия по https-адресу НЕ видят данных друг друга.
   Перенос: в старой версии «Экспорт в файл», в новой «Импорт из файла».
3. После переноса сделайте экспорт ещё раз и храните файл вне браузера.

КАК ВЫЛОЖИТЬ (бесплатно, любой из способов)
  GitHub Pages: создайте репозиторий, загрузите ВСЕ файлы и папку icons в корень,
    Settings → Pages → Branch: main / root. Адрес будет вида
    https://ваш-логин.github.io/имя-репозитория/
  Netlify Drop (app.netlify.com/drop): перетащите папку целиком.
  Cloudflare Pages / любой свой хостинг: загрузите папку как есть.
  Файлы кладутся вместе, в одну папку, структуру менять нельзя.

УСТАНОВКА
  Android Chrome: откройте адрес → меню ⋮ → «Установить приложение»
    (или «Добавить на главный экран»).
  Chrome на ПК: значок установки справа в адресной строке → «Установить».
  После установки приложение открывается в отдельном окне и работает без интернета.

ОБНОВЛЕНИЕ
  Выложите новый index.html и sw.js (в sw.js номер версии подставляется сборкой сам).
  Приложение само замечает новую версию (при открытии и при возвращении в него)
  и показывает внизу «Доступна новая версия — Обновить». Либо вручную:
  меню ☰ → «Проверить обновление». Данные при обновлении не затрагиваются.
  Если в этот момент открыта форма с несохранёнными правками, перед обновлением
  программа спросит подтверждение.

ЧТО ПРОВЕРЕНО
  В Chromium по http: манифест читается, 4 значка отдаются, воркер регистрируется,
  9 файлов попадают в кэш, после отключения сети программа открывается и
  сохранённые настройки на месте; выпуск новой версии замечается, баннер «Обновить»
  срабатывает, страница перезагружается на новую версию, данные сохраняются. На телефоне установку не проверял.
